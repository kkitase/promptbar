# Prompt Bar 🚀

Chrome のサイドパネルでプロンプトをスマートに管理・コピー・整理できる Chrome 拡張機能です。
AI との対話をもっとスムーズに、効率的に。

![Prompt Bar Header](icons/icon128.png)

## ✨ 特徴

- **サイドパネル常駐**: ブラウジングを邪魔せず、いつでもプロンプトを呼び出せます。
- **迅速なコピー**: ワンクリックでお気に入りのプロンプトをクリップボードに保存。
- **柔軟な管理**: 直感的な UI でプロンプトの追加、編集、削除が可能。
- **タグ分類**: 目的別にプロンプトをタグで整理し、素早くフィルタリング。
- **お気に入り機能**: よく使うプロンプトはスターを付けて上部に固定。
- **ダークモード対応**: 目に優しいデザインで、昼夜を問わず快適に利用可能。
- **大容量対応**: 最大 10,000 文字までの長いプロンプトもしっかり保存。

## 🛠 インストール方法

1. このリポジトリをクローンするか、ZIP でダウンロードして展開します。
2. Google Chrome で `chrome://extensions/` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」ボタンをクリックします。
5. 展開したプロジェクトのルートディレクトリ（`manifest.json` があるフォルダ）を選択します。

## 🚀 使い方

1. Chrome の拡張機能メニューから「Prompt Bar」をピン留めします。
2. アイコンをクリックしてサイドパネルを開きます。
3. 「+」ボタンでプロンプトを追加します。
4. プロンプトカードのコピーアイコンをクリックして、AI チャットなどに貼り付けてください。

## 📝 技術スタック

- **Manifest V3**
- **HTML/CSS/JavaScript (Vanilla JS)**
- **Chrome Storage API** (データのローカル保存)
- **Chrome Side Panel API**
